# 公开范围与样例说明

整理日期：2026-10-08。项目名称：U2-dw电量显示工具。

## 发布内容

- 托盘程序、HID 读取模块、诊断工具源码及测试代码。
- 使用说明、协议与估算方法、历史验收结论。
- 脱敏的校准文件、校准证据摘要和历史查询快照。
- 2026-10-05 的 30 项 Python 测试和 13 项 C# 组件测试结果。

源码与本地已验收实现一致；发布整理没有重新运行实现测试或实机验收。公开整理清单记录源文件哈希，不能替代运行验收。

## 校准样例

程序沿用 `diagnostics/full-battery-calibration.json`，其 414 参考值来自原开发鼠标的一次满电观察。证据摘要中的布尔确认仅描述那次历史观察，不表示下载者的鼠标经过校准，也不表示设备当前充满。完整放电准确度及跨鼠标适用性未验证。

公开副本删除了设备实例路径、精确时间和用户回复原文；保留算法所需字段、选样值及原始记录哈希。原始记录由开发者本地保留，哈希本身不能让下载者独立复核未公开原件。若建立自己的校准，应基于真实灯态确认和取下后的有界记录，不能仅修改布尔值来宣称验证完成。

## 不随仓库发布

官方更新器、提取固件与反汇编、第三方分析依赖、USB 抓包、原始设备枚举和输入记录、操作确认日志、运行状态及本机环境记录均保留在原研究目录。诊断文档中的历史文件名不表示这些材料已公开。

静态固件分析工具需要自行准备对应材料及分析依赖；它们不是日常运行依赖。测试可使用随附脱敏快照和校准摘要，实机兼容性仍需在目标设备验证。

## 后续维护

公开仓库作为独立 Git 工作目录维护；原研究目录不自动同步到公开仓库。后续更新应逐项复制、检查差异再提交，避免将原始记录加入版本控制。`.gitignore` 默认排除新增诊断数据，仅放行本次审核的五份 JSON 文件。
