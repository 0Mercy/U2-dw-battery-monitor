## 常见问题与处理

| 现象 / 风险 | 已知原因或状态 | 处理方式 |
|---|---|---|
| GET_REPORT 返回错误 31 / STALL | 当前设备拒绝该标准请求 | 使用已确认的输出查询与中断输入响应路径；不持续重试 GET_REPORT |
| 充电或取下后长时间数值不变 | 读到接收器缓存，上报周期未知 | 不把不变值当成实时采样；保存真实观察，不据此宣布满电 |
| 数值存在但鼠标版本为 `0000` | 断连对照已观察到旧电压保留 | 隐藏有效估算，标为未连接或状态未知 |
| 回复错配或读取超时 | 协议无命令回显；并发访问是可能原因 | 先确认只有一个查询客户端；不能将所有超时都归因于并发 |
| 接收器拔出或状态变化导致命令行异常 | 枚举错误及部分 CLI 检查会抛出异常 | 托盘层捕获、显示未知并定时重试；本轮拔插实机通过；当前 CLI 没有自动恢复循环 |
| 中文输出编码错误 | Windows 环境编码可能不一致 | 使用 UTF-8 文件读写和 `PYTHONIOENCODING=utf-8` |
| 复跑脚本覆盖证据 | 部分工具固定输出文件名 | 新记录优先用新的 `--out`；固定输出脚本先保存旧结果 |

`query_version.py` 直接执行会改写 `version-query-result.json`；`analyze_battery_thresholds.py` 会改写 `battery-threshold-emulation.json`。`monitor_voltage.py` 只查电压，不能代替带前后鼠标版本校验的百分比读取。

校准加载器核对版本、参考值及人工确认字段；它**不会在每次加载时重新校验原始序列 SHA-256**。历史验证及本次文档审计均确认记录哈希一致，不能描述为运行时完整性保证。

## 按变化选择验证

仅在任务要求测试或验证时执行以下实现检查；未执行的项目标记为未验证，并解释影响。

- **协议或解析变更**：对照已有原始响应与静态处理分支，再做有界实机读取；覆盖失败、断连、未知固件和前后版本变化。所有设备查询串行。
- **百分比或校准变更**：离线核对阈值、量化边界、输出范围、单调性、异常输入及校准证据；准确度结论另需自然放电观察。调整公式不能自动继承旧验证结果。
- **托盘初版验收**：正常显示及“估算”说明；关鼠标、拔基站、重新连接、睡眠唤醒；刷新和定时查询不重叠；重复启动不并发读取；退出停止查询；失败时及时隐藏旧数字。记录运行时长、资源占用与观察结果。
- **打包与安装**：在无开发环境的 Windows 上检查启动、路径、校准文件、非管理员读取与退出；没有实际执行前不宣称可独立部署。
- **文档变化**：检查相对链接、参数定义、事实与提案的区分及证据指向；不为文档更新自动触发硬件操作。
