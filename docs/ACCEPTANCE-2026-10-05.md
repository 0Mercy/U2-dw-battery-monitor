## 本次发现并修复

1. **输出报告短写入误判成功**：已在传输层要求写入恰好 16 字节，否则返回错误并清理挂起 I/O。保留了 修复前失败（仅本地保留：`../diagnostics/acceptance-20261005-013837/python-before.json`）。
2. **UI 接受无穷大电压**：UI 增加有限值及 3–5V 开区间校验。正常读取层不会生成无穷大，此项是异常输入防护。保留了 修复前组件失败（仅本地保留：`../diagnostics/acceptance-20261005-013837/tray-components.json`）。
3. **畸形校准 JSON 分类不准确**：校准根对象、证据对象和确认对象显式检查结构，将无效校准转换为可识别错误。
4. **校准确认接受非布尔真值**：原先字符串 `"false"` 或整数 `1` 可能被当作确认，现要求严格的布尔 `true`。修复前校准结果（仅本地保留：`../diagnostics/acceptance-20261005-013837/python-schema-before.json`）保留。

没有修改分段估算公式、阈值、校准数值或原始历史实验。为了隔离 C# 测试，增加了内部构造入口；生产启动仍使用原来的公开入口、状态目录和可见图标。
